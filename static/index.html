    Advanced / technical details
    Research layer vs. product layer

    This demo has two layers. The KGRec research layer evaluates popularity, ALS collaborative filtering, and content-based recommendation on an academic dataset. The Real Song Mode uses NetEase search plus hybrid ranking to turn that recommendation logic into a real-song user experience.
